# Lensy CLI

`lensy` checks whether AI search engines and coding agents can find and read a docs page, and reports two scores out of 100: Coding agents and AI search. It runs the same engine as [perseveranceai.com](https://perseveranceai.com).

Not released yet. The command reference and install steps land with the first early-access version.

Packages:
- `cli/`: `@perseverance-ai/lensy`, the `lensy` command.
- `core/`: `@perseverance-ai/lensy-core`, the engine API.

See [CONTRIBUTING.md](CONTRIBUTING.md) to build and test, and [SECURITY.md](SECURITY.md) to report a vulnerability.
